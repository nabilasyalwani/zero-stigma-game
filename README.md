# Zero Stigma

**Zero Stigma** adalah game edukasi berbasis web yang bertujuan untuk meningkatkan pemahaman masyarakat tentang penyakit kusta serta mengurangi stigma negatif yang melekat pada penderitanya. Game ini mengajak pemain untuk melihat permasalahan kusta dari sudut pandang penyintas, melalui interaksi sosial dan pengambilan keputusan.

Game ini dikembangkan menggunakan **Next.js** berbasis **React**.

## Konsep Game

Dalam game ini, pemain berperan sebagai seorang pendatang yang mengidap penyakit kusta dan tinggal di sebuah lingkungan perumahan. Seiring berjalannya waktu, pemain harus berinteraksi dengan warga sekitar, termasuk tokoh seperti Pak RT, untuk membangun kepercayaan dan menghapus stigma negatif yang ada.

Permainan dibagi ke dalam beberapa hari, yang merepresentasikan lamanya penyakit diderita serta progres interaksi sosial pemain.

## Alur Cerita Singkat

Pemain memulai permainan sebagai pendatang baru di lingkungan perumahan. Seiring berjalannya cerita, pemain akan:

- Mengalami tahapan penyakit kusta (dalam game ini digambarkan hingga tahap _Borderline Tuberculoid_)
- Menghadapi respons masyarakat yang beragam, termasuk stigma dan penolakan
- Membuat pilihan dialog yang memengaruhi kepercayaan warga

Di akhir permainan, pemain akan mendapatkan apresiasi dari masyarakat serta pesan edukatif mengenai pentingnya penanganan dini dan dukungan sosial bagi penderita kusta.

## Fitur Gameplay

- Interaksi dialog dengan warga (contoh: Pak RT)
- Sistem pilihan dialog yang memengaruhi respons warga
- Indikator **hati** sebagai representasi kepercayaan masyarakat dan nyawa pemain
- Sistem hari untuk menunjukkan progres waktu dan perkembangan penyakit
- Ending berupa penghargaan dan pesan edukatif

## Tujuan Edukasi

Game ini dirancang untuk:

- Memberikan pemahaman dasar tentang penyakit kusta
- Menunjukkan dampak stigma sosial terhadap penderita
- Mendorong empati dan sikap inklusif terhadap penyintas kusta
- Mengedukasi pentingnya pengobatan dan dukungan sosial
